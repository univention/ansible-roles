# UCS Ansible Roles 

This repository only contains ansible roles usable in an ansible-playbook to install and bootstrap UCS.

## Create a new role

In order to create a new role, execute:

```shell
ansible-galaxy init <name-of-role>
```

*Replace <name-of-role> with an appropriate name of your role **without** `<`,`>`.*
